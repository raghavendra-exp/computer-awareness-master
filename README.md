## 🌟 Executive Summary

**Computer Awareness Master** is a production-grade, all-in-one educational web platform engineered specifically for aspirants targeting **IBPS RRB Officer Scale-I & Office Assistant (Multipurpose), SBI Clerk / Junior Associate, IBPS Clerk / CSA, and RBI Assistant** examinations.

Unlike static GK repositories or generic MCQs, this platform bridges theoretical computer architecture with practical banking examination strategy. It features **10 interactive real-time visual simulators**, an authentic **508+ bilingual question bank** with IBPS 5-option patterns and negative marking, procedural drill generators, **Leitner 5-box spaced repetition**, and a comprehensive **Computer Readiness Score** diagnostic engine.

## 🚀 Key Feature Pillars

### 1. 📚 12 Complete Conceptual Mastery Modules
Every module includes structured theoretical notes, exam-weightage breakdowns, shift-wise PYQ trend analysis (2020–2026), formula cheat sheets, and banking examination trap alerts:
1. **Computer Fundamentals & Generations**: Von Neumann architecture, vacuum tubes to AI, analog vs. digital vs. hybrid.
2. **Hardware Architecture & I/O Subsystems**: CPU registers, ALU, CU, buses, motherboard chipset, optical vs. magnetic vs. flash storage, printer types (impact vs non-impact).
3. **Memory Hierarchy & Storage Units**: Register → L1/L2/L3 Cache → RAM/ROM → SSD/HDD hierarchy, SRAM vs DRAM, PROM/EPROM/EEPROM, virtual memory, paging, byte conversions (KB, MB, GB, TB, PB, EB, ZB, YB).
4. **Number Systems & Digital Logic**: Binary, Octal, Decimal, Hexadecimal, 1's and 2's complement, ASCII, UNICODE, BCD, logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR).
5. **Operating Systems & System Software**: Kernel vs Shell, Process Scheduling (FCFS, SJF, Round Robin), Deadlock conditions, Windows/Linux/Unix command cheat sheet.
6. **MS Office 365 Suite**: Word, Excel, and PowerPoint banking shortcuts, Excel formula engine (`SUM`, `AVERAGE`, `VLOOKUP`, `INDEX-MATCH`, `IF`), PowerPoint presentation views.
7. **Keyboard Shortcuts & Accelerators**: Windows global hotkeys, navigation, editing, function keys (F1–F12), and recurring exam traps.
8. **Networking Architecture & Topologies**: LAN, MAN, WAN, PAN, SAN, Star, Mesh, Bus, Ring, Tree, transmission media (Twisted Pair, Coaxial, Fiber Optic), network devices (Hub, Switch, Router, Gateway, Bridge, Repeater).
9. **Network Protocols & The 7-Layer OSI Model**: Application to Physical layers, Protocol Data Units (PDUs), TCP/IP suite, port numbers (HTTP 80, HTTPS 443, FTP 20/21, SSH 22, SMTP 25, POP3 110, IMAP 143, DNS 53, DHCP 67/68).
10. **Internet, Web & Cloud Computing**: DNS resolution hierarchy, IPv4 vs IPv6, URL breakdown, Cloud deployment models (IaaS, PaaS, SaaS), Web 2.0 vs Web 3.0.
11. **Cybersecurity, Malware & Cryptography**: Virus vs Worm vs Trojan, Ransomware, Spyware, Rootkits, Phishing, Spoofing, MITM, DDoS, Symmetric vs Asymmetric encryption, SSL/TLS, Firewalls.
12. **Database Management Systems & SQL**: RDBMS concepts, ACID properties, Keys (Primary, Foreign, Candidate, Super), Normalization (1NF to BCNF), DDL vs DML vs DCL vs TCL commands.
13. **Programming Concepts & Data Structures**: Compilers vs Interpreters, High-level vs Low-level languages, OOP pillars, Stacks (LIFO), Queues (FIFO), Linked Lists, Trees, Graphs.
14. **Digital Banking Systems & Financial Tech**: Core Banking Solutions (CBS - Finacle, BaNCS), NEFT, RTGS, IMPS, UPI, NPCI infrastructure, AePS, CTS-2010, USSD (*99#), SWIFT, IFSC & MICR encoding.
15. **Emerging Technologies**: AI, Machine Learning, Blockchain, IoT, Quantum Computing, Big Data, FinTech automation.

## ⚡ Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (Version 18.0 or newer recommended)
- [Git](https://git-scm.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/raghavendra-exp/computer-awareness-master.git
cd computer-awareness-master
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Locally in Development Mode
```bash
npm run dev
```
Open your browser and navigate to the displayed local server address (typically `http://localhost:5173/`).

### 4. Build for Production
```bash
npm run build
```
This compiles and bundles optimized static assets into the `dist/` directory.

### 5. Preview Production Build Locally
```bash
npm run preview
```

## 🌐 Deploying to GitHub Pages

This project is pre-configured with a dual-mode automated GitHub Actions deployment workflow.

### Automated Deployment (GitHub Actions)
1. Push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/raghavendra-exp/computer-awareness-master.git
   git branch -M main
   git push -u origin main
   ```
2. Navigate to **Settings** > **Pages** in your GitHub repository.
3. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions** (or `gh-pages` branch if using the automatic peaceiris action).
4. Within 1-2 minutes, your website will be live at:
   `https://raghavendra-exp.github.io/computer-awareness-master/`
